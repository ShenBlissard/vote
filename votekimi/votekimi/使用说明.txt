========================================
  班级投票系统 · 使用说明（v7）
========================================

一、启动方式（三种）
----------------------------------------
1.【启动投票系统.bat】双击运行（推荐日常使用）
   - 服务器就绪后浏览器才自动打开（不会出现"无法访问"）
   - 服务器意外停止会自动重启
   - 停止系统：双击「停止投票系统.bat」，或直接关闭黑色窗口
2.【后台静默运行.bat】无黑窗口后台运行，适合挂在电脑上长期使用
   - 首次请先用方式1完成安装和构建
   - 停止系统：双击「停止投票系统.bat」
3.【停止投票系统.bat】随时一键停止

注意：电脑关机或休眠时系统会停止，重新运行启动脚本即可；
      数据都保存在 data 文件夹，重启不会丢失。

二、发起投票（4步）
----------------------------------------
第1步 基本信息：主题、说明、截止时间
      投票选项（由发起人决定）：
      □ 允许投票人在截止前修改自己的选票

第2步 候选人：
      - 支持导入：Excel(.xlsx) / Word(.docx) / 图片（自动OCR识别）/ 文本
        导入后可继续手动检查、增删；「排版」按钮可随时整理格式
      - 名单支持一行多个名字：用英文逗号、中文逗号、顿号、分号或空格
        分隔都可以（如"张三,李四、王五 赵六"一行写四个人）
        任何其他符号（如OCR误读出的 < * 等）也自动当作分隔符处理
      - 排版规则（导入自动/手动点击「排版」）：≤10人竖排每名一行；
        >10人紧凑横排（名字间中文逗号、口令紧跟名字），长名单不翻页
      - □ 候选人乱序展示（每位投票人页面打开时随机一次，之后固定不变）
      - 每人投票人数：最少X人 ~ 最多Y人
        例：1~1=单选；3~3=必须投3人；2~5=投票人自选2至5人

第3步 参与人：
      - 同样支持文件导入；Excel 双列时可分别选择「姓名列」和「口令列」
      - 口令写法全部自动识别（一行可写多人多组）：
        "张三,0421" / "张三，0421" / "张三 0421" / "张三0421"（连写）
        "啊啊啊 1234 哇哇哇 8790"（一行两组，空格逗号混用都行）
        （规则：紧跟姓名的纯数字视为该人的口令；1位数字视为同名后缀不拆分）
      - 可一键为没有口令的人生成随机口令
      - 同名同学请加后缀区分（如：张三-大）

第4步 公布设置（截止后仍可随时在管理页调整）：
      - 匿名投票（默认开启）：管理界面不显示谁投了谁，只显示票数与
        参与情况；取消勾选后，你的管理界面会显示每个人的投票对象
      - 票数公布：全部公布 / 只公布票数前N名 / 都不公布
        （"前N名"按最终排名计、含并列；若因并列导致所选名次不存在，
          系统按"宁可少公布"自动向下收缩名次并固定，之后可再改）
      - 参与情况：公布已投+未投 / 只公布已投 / 只公布未投 / 都不公布
        （公布票数时会同时显示"百分之几的参与者投了TA"，不受此开关影响）
      - 截止后：自动公布 / 由我手动公布

三、投票人操作
----------------------------------------
点微信群链接 → 选择自己的姓名 →（如设置了口令，输入口令）→ 投票。
- 页面每3秒自动更新，无需手动刷新：发起人公布/撤回结果、修改截止
  时间，投票者界面几秒内自动跟上
- 投票期间任何票数对投票者不可见；截止后自动/手动公布结果
- 截止后再打开链接即可看到被公布的结果（按票数排名）
- 通过微信群投票链接进入的页面不含任何发起人内容（无返回、无管理
  入口）；发起人从首页"我发起过的投票"点进投票页时才有「← 返回首页」

四、管理页功能
----------------------------------------
- 顶部有「← 返回首页」链接，可回到"我发起过的投票"列表
- 页面每3秒自动更新（已投名单、票数、参与率实时跳动，无需刷新）
- 实时查看参与名单，自动分成「已投票」「未投票」两个分组
- 「完整结果（仅发起人可见）」：按票数排名（并列同名次），显示
  "百分之几的参与者投了TA"，投票期间也可实时查看
- 匿名投票开启时，参与名单和导出均不显示每个人的投票对象
- 修改截止时间：提前、推迟都可以；把已截止的投票改到未来=重新开启
- 立即截止 / 公布结果 / 撤回公布
- 公布设置随时调整（匿名/前N名/参与情况/自动公布），保存后有绿色提示
- 导出：Excel表格 或 复制为排版好的文字（直接粘贴到微信群）
- 口令对照表：复制后私下发给每个人
- 投票截止后「分享投票」栏目自动收起（重新开启后恢复）

五、防冒名说明
----------------------------------------
每位参与人可设置独立口令（如学号后4位）。设置了口令的人，
必须输入正确口令才能投票或修改选票，别人无法代投。
请把口令私下发给每个人，不要发在群里。

六、数据备份
----------------------------------------
所有数据在 data 文件夹（vote.db）。备份=复制该文件夹；恢复=粘贴覆盖。

七、常见问题
----------------------------------------
1. 页面打不开？
   - 黑窗口是否开着？（用后台模式则看任务管理器有无 node.exe）
   - 重新双击「启动投票系统.bat」
 2. 图片导入识别不准？
   系统已支持深色模式截图（自动反转）、高精度模型并自动放大小图。
   印刷体和正常姓名识别效果很好，但生僻字、艺术字、模糊照片仍可能
   出错（如"呃呃呃"这类罕见字）。识别不出有效姓名时会明确提示，
   不会误报"重复"。导入结果会先放进文本框，请顺手检查再进入下一步。
 3. 忘记管理链接？
   用创建时的电脑和浏览器打开首页，在「我发起过的投票」找回
   （列表会自动清理已不存在的旧投票）。
   建议创建后立即把管理链接发到自己的微信"文件传输助手"。
 4. 图片导入时提示"识别引擎加载超时"？
   请刷新页面重试，或改用文本导入（把名字打在记事本里再导入）。
 5. 代码改动后？
   运行「重新构建.bat」再启动。
